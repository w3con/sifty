# Приёмка: Select на любой раскладке

## 1. Итог и статус

Обработчик Select использует физическую клавишу KeyY вместо введённого символа. Проверка координатора: реализация и перенос приняты по фактическому diff и сохранённым свидетельствам сборки и браузерной проверки. Владелец одобрил перенос и отправку Git словами «да, делай»; пользовательская проверка клавиши ещё ожидается. Исправление находится в main, коммит `e295b21`; production не обновлён. Карточка остаётся review, формальное закрытие не выполнялось. Остальные накопленные документы и89дизайн-материалов также закоммичены; отправка ожидает выполнения K.3.

## 2. Где посмотреть

Исходники: [обработчик клавиатуры в main](../../../../frontend/main.tsx), строки121–131. Основной checkout содержит исправление; в использующем main staging-интерфейсе <http://localhost:8081> можно выбрать вакансию в Inbox и нажать физическую Y при английской и русской раскладках. Оба нажатия должны выполнять Select. Самостоятельная проверка этой живой страницы после Git-переноса не выполнялась; браузерные свидетельства ниже относятся к собранной рабочей копии. Production8080 пока использует предыдущий выпущенный источник.

## 3. Что изменилось

Добавлена проверка `e.code === 'KeyY'` и подавление стандартного действия для этой клавиши. Источник входных данных — событие браузера; логика остаётся в существующем обработчике, кнопка и данные приложения не менялись. Условие Select больше не зависит от символа `e.key`. Накопленные инструкции, планы, сведения об окружениях и одобренные владельцем макеты сохранены отдельными смысловыми коммитами. Прежняя история не переписывалась, промежуточные коммиты исправления в main не переносились.

## 4. Что я проверил

Координатор прочитал фактический diff, вывод сборки и пяти проверок Chromium. Проверены события y/KeyY и н/KeyY, отсутствие Select для y/KeyZ, защита поля ввода и Ctrl+Y. Браузер работал со явно обозначенными искусственными вакансиями и перехватом API; настоящие данные не изменялись. Это проверка событий браузера, а не ручное переключение системной раскладки. Существующие ограничения для модальных окон, модификаторов и композиционного ввода сохранены в коде. Сборка TypeScript/Vite прошла; широкие тесты SKIPPED, а не passed. Независимо проверены метаданные исполнителя: opencode-go/deepseek-v4.1-flash, 53 сообщения помощника на момент проверки.

При приёмке переноса координатор проверил семь новых коммитов, фактическое трёхстрочное изменение приложения, сохранение прежнего изменения DESIGN-2 в MAP и согласование runtime-документа с уже выпущенным production. Основной checkout чист; все существовавшие рабочие копии сохранены. Свидетельства исполнителя подтверждают прохождение действующих commit/secret-проверок, отсутствие баз данных и локальных runtime-каталогов среди новых путей и совпадение main.tsx с принятым исходником. Проверены метаданные второго исполнителя: opencode-go/deepseek-v4.1-flash, 66 сообщений на момент приёмки K.2. Новые сборки и широкие тесты не запускались, поскольку принятый код не изменился.

## 5. Спорные решения и компромиссы

Выбрана согласованная привязка к физической клавише: символ y с другой физической клавиши не вызывает Select. Настройки раскладок и новый слой конфигурации не добавлены. Для Git выбран обычный push с сохранением существующей истории. При прохождении действующих проверок русская цитата согласования в обзорном MAP заменена датой (точная цитата сохранена в карточке); абсолютные пути инструкции заменены на "$PWD", русские подписи демонстрационного HTML переведены на английский. Проверки не отключались; исходные файлы сохранены в recovery-копии.

## 6. Что учесть дальше

Основной каталог зависимостей не исправлен; штатное восстановление — `npm ci`.
