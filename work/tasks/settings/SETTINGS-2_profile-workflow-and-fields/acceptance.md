### 3. Что изменилось

- Сервер атомарно объединяет только выбранный раздел с текущим сохранённым профилем. Разные параллельные сохранения не затирают друг друга. Отложенный старый ответ не откатывает свежие значения на клиенте. Несохранённые черновики сохраняются.
- Нормализованный Save без изменений закрывает редактор без новой записи, пересчёта или вызова модели. Cancel относится к одному разделу. Техническая ревизия осталась внутри для происхождения данных и устаревших оценок, интерфейс версий убран.
- Первая пустая строка существует только в черновике. Полностью пустая строка не сохраняется; частичная остаётся с сообщением о видимом поле и человеческим номером строки. Старые частичные Experience не блокируют неизменённый Save и другие разделы.
- Пустой новый профиль не получает подтверждённые поля из старой конфигурации при GET; исходные legacy-данные сохраняются отдельно. Явный пустой staging-старт выполнен через существующий API, без удаления документов и оригиналов.
- Причина обнаруженных таймаутов: локальная модель тратила120секунд на reasoning перед структурированным ответом. Для извлечения фактов запрос теперь передаёт think=false; провайдер, модель, таймаут и остальные модельные этапы не изменены.
- Ошибки документов объясняют причину и действие; техническая строка скрыта в раскрываемых подробностях. Сохранённый адрес источника виден. Исчезли дубли Analyze/Retry и ложное постоянное сообщение об успешном старте после ошибки. Refresh scoring повторяет только локальное обновление контекста и баллов.

### 5. Спорные решения и компромиссы

В плане я выбрал сохранение последнего явно отправленного значения одного раздела вместо конфликтов версий на экране; владелец одобрил этот план. Остальные разделы защищены атомарным серверным объединением; CAS для принятия фактов сохранён. Незавершённую новую Experience требуется дополнить компанией и должностью, но сохранённые старые частичные строки не теряются и не ломают no-op. Thinking отключён только в извлечении структурированных фактов, по измеренной причине таймаута, без смены провайдера и без произвольного увеличения времени ожидания.
