## Технические решения

Фото хранится отдельно от CV и фактов: profile-avatar.json указывает на файл под profile-avatar/ через существующий Dirs. Новое изображение записывается прежде атомарной замены указателя; неудачная замена сохраняет прежнее. Схема SQLite и версия профиля ради фото не меняются. Форматы/размер берутся из существующего Runtime configuration/capabilities, сервер полностью декодирует PNG/JPEG/WebP; для WebP использован golang.org/x/image/webp. API и hooks выполняют запросы, domain service проверяет/сохраняет файлы, представление получает данные и callbacks. Общие компоненты уже использовались в Profile — их оформление изменено совместно, без отдельной библиотеки/галереи.
