# APP-3 — Answers sourced from the knowledge base with a per-question think modal

**Epic:** application-preparation
**Created:** 2026-11-03
**Status:** founded
**Short card:** steps and acceptance criteria live here.

## Why this work exists

Answers are not generated by the model for every question each time. By default each inspected question is answered from the knowledge base, which holds the material prepared earlier (see the Settings epic). Next to each answer sits a "think" affordance: pressing it opens a modal where the model works the question through in a conversation, asks the user what it needs, and on resolution writes the outcome back to the knowledge base so later questions are answered better. Generation is therefore lazy and on demand, ordered by priority with the job the user is actively viewing first, never eagerly for every pre-selected job.

## Acceptance criteria

- The work is complete when each inspected question is answered by default from the knowledge base, a per-question think modal lets the model and user resolve a question interactively, and the resolved outcome is written back to the knowledge base for reuse.

- The knowledge-base answer store contract, which is owned by the Settings epic.
