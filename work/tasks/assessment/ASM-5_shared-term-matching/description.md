## Зачем

Владелец выбирает или вводит навык/роль, а варианты вроде React / React.js / Reactjs сопоставляются одинаково в вакансиях с его собственных нишевых сайтов и внешних источников. Дословный вопрос и контекст находятся в [обсуждении Profile](../../settings/SETTINGS-2_profile-workflow-and-fields/comments.md). Закрытый IT-only список не подходит; наличие термина в справочнике не условие сбора вакансии.

## Границы

Это применённая нормализация, не отдельная неиспользуемая база или новый scoring engine. Входит локальный справочник, расширяемый ввод, одинаковое распознавание и подключение к нынешнему ранжированию. Универсальное понимание текста, LLM learning, все языки мира, taxonomy per website, новый weighted engine, новые scraping feeds и платные источники исключены.

## Оценка и зависимости

- **Complexity:** 8 — reference-data import, неоднозначность терминов, UI и согласованный matcher; оставляем одной карточкой, чтобы словарь сразу реально использовался, а не требовал ещё одного проекта.
- **AI preparation:** 20–30мин; **implementation:** 75–115мин; **acceptance:** 25–35мин.
- **Total AI elapsed:** 120–180мин, внешняя доступность/download отдельно; стоимость подписки неизвестна, runtime LLM calls не нужны.
- Зависит от SETTINGS-3 для окончательного контракта и SETTINGS-1 для actual ranking base. Уточняет соответствующую часть будущего INBOX-1, не запускает весь INBOX-1. Выполнение не одобрено.
