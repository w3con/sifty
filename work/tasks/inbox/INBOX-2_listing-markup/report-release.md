### 5. Спорные решения и компромиссы

- Прерванный сбор: ежедневный сбор, начатый в 18:27, прерван остановкой сервера по вашему слову. В базе остался его след: запись запуска со статусом «идёт» и без времени окончания. Сервер сообщает об «идущем» сборе до следующего запуска. Скрипт удаления Remote3 из-за этой записи отказался работать; я запустил его с отключённой одной проверкой статуса (процесс сбора проверен как мёртвый, остальные защиты скрипта и защита вакансии 7 остались), записи в базе вручную не правил.
- Число Fits you сместилось у части вакансий из-за правил оценки места, которые пришли из main; это не часть вашей карточки, но видно в числах.
- Правило записи навыков осталось прежним (короткие фразы до трёх слов становятся навыками; ключи C, C++ и C# совпадают): решение владельца перенести правку в SETTINGS-10 после выпуска.

### 6. Что учесть дальше

- Обязательные продолжения: карточка SETTINGS-10 (правило записи навыков по словарю, «Move to skills / Move to facts», ключи навыков C / C++ / C#, «AI coding tools» в словаре); запись прерванного запуска сбора: сервер не закрывает такие записи при старте (в коде есть восстановление очереди оценки, но нет такого для запусков сбора), нужна небольшая карточка про это, пока достаточно следующего запуска сбора, он создаст новую запись.
